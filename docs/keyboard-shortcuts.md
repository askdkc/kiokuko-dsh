# 選択画面のキー操作

質問カードは、質問IDに関係なく番号で選べます。通常実行、Enno、Deep、Orca、Lisp、承認画面も同じ操作です。

| 操作 | キー |
| --- | --- |
| 候補を選択 | 数字、または Cmd+1〜9（MacのSafari、Windows、LinuxはCtrl） |
| 10件以上の候補 | 番号を続けて入力。Backspaceで訂正 |
| 単一選択を確定 | Enter |
| 複数選択のチェック切替 | 9件以下は数字。10件以上は番号の入力後にSpace |
| 複数選択の回答を送信 | Cmd/Ctrl+Enter |
| 複数質問 | Enterで次へ。最後の質問で回答一式を送信。「前の質問」で戻っても下書きを保持 |
| 自由入力 | 入力欄に入力しEnterで確定。Shift+Enterで改行 |
| 閉じる・取消 | Esc。ホストが指定した閉じ方を維持 |

検索欄や数値入力欄の数字は入力内容として扱います。IME変換中やキーを押し続けている間は選択・送信しません。回答済みの画面では選択と送信を無効にします。

Diffレビューでは、比較対象・ターン・タスク・モデルの選択ボタンを開いてから数字とEnterで確定します。ファイル一覧は番号で表示対象を変え、Spaceで分析対象のチェックを切り替えます。分析は「分析する」を押すまで始まりません。

「質問、相談、会話」を選んだ後は、同じセッションの会話を引き継ぎます。内容から明確な新しい作業依頼だと判断できる場合は、その作業の分類へ切り替えます。別セッションへ会話の選択を持ち越しません。

## 回帰テスト

```sh
npm ci --prefix tests/fixtures/dsh-runtime
npx playwright install chromium
npm run test:shortcuts:web
KIOKUKO_SHORTCUT_RUNTIME=dsh-runtime npm run test:shortcuts:web
```

梱包済みKiokukoを一時プロファイルの実DSHへインストールし、実際の質問サービスから候補を表示します。画面の表示、キー入力、受け取った回答、Diffレビューとの干渉、狭い画面を検証します。モデル呼び出しは不要です。既存のDSHプロファイルは変更しません。ブラウザ未導入や必須画面の欠落は失敗になります。

画像を残す場合は `KIOKUKO_KEEP_SHORTCUT_EVIDENCE=1` を指定してください。テスト出力に一時ディレクトリが表示されます。テスト全件にはビルド出力を作り直すケースがあるため、梱包・ブラウザ検証と全件テストは同時に実行しないでください。
