# 基本概念

Kiokuko for DSHは4つの境界を組み合わせます。Akinatorは依頼を実行可能なintake
profileへ整理し、memory retrievalは関連するuntrusted contextを供給し、
役小角(enno-oduno)は計画・実行・検証・内省を制御し、ledgerはsanitized lifecycle
evidenceを記録します。

active workflowは1つのcanonical repositoryと現在のDSH session routeに属します。
sessionの再bindでroute epochが変わり、resume tokenとexecution leaseはその正確な
routeへ束縛されます。
