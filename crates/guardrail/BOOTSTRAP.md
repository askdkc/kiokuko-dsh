# Explicit bootstrap boundary
This dependency-free crate's manifest, API-only stubs and test harness were created before the first governed feature cycle. This scaffolding is not functionality and is not claimed as TDD-verified implementation. Each behavior is subsequently introduced only after its corresponding compiled test executable fails an actual assertion through the Common Lisp runner. Compiler/setup failure uses exit 2 and cannot count as assertion RED (exit 1). Tests allocate and remove their own temporary build directories. No product repository is modified by this bootstrap.
