# Benchmark

Follow SOUL and the current host directive. This skill grants no extra permissions, model changes or delegation. Use the current model and proportionate evidence.

State the claim and inspect what the timer counts and excludes. Verify outputs and count failed, skipped and retried work. Identify the bottleneck and check physical limits. Match versions, data, production settings and cache state. Interleave at least five runs per side for comparisons; a requested one-run estimate must be labeled. Profile separately from timed runs.

## Completion

Report baseline, candidate, method, sample count, distribution and uncertainty. A faster failure or no-op is not a speedup. Do not select a winner from unequal configurations or noise; explain what further measurement can resolve.

Read [worked cases](references/cases.md) only when the decision or failure boundary is unclear. Do not load unrelated specialists or repeat completed checks without new evidence.
