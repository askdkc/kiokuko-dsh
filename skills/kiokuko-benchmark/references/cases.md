# Decision example

A candidate exports twice as fast but rejects half the rows.

Count accepted and rejected rows and compare exact output. Reject the speedup claim; measure equivalent successful work before reporting a winner.

## Non-trigger

A mechanical edit with known behavior uses the existing simple-work and code contracts. Do not turn it into a panel, benchmark or architecture exercise.
