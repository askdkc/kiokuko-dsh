# Architecture

Follow SOUL and the current host directive. This skill grants no extra permissions, model changes or delegation. Use the current model and proportionate evidence.

Write caller usage first. Name domain concepts, ownership, inputs, failures and effects before choosing representations. Compare two structurally distinct alternatives only when a consequential uncertainty remains. Evaluate compatibility, complexity, testability and migration cost against explicit constraints. Keep mechanical changes on the simple-work route.

## Completion

Deliver an interface sketch, decision, rejected alternative and focused verifier. Revisit the design when repeated workarounds expose a false premise. Do not commit broken scaffolding or replace required compatibility with a clean-slate assumption.

Read [worked cases](references/cases.md) only when the decision or failure boundary is unclear. Do not load unrelated specialists or repeat completed checks without new evidence.
