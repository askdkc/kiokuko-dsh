# Decision example

A new public field can be represented as optional properties or a discriminated union.

Write the two caller examples. Compare invalid states, serialization compatibility and migration cost. Choose the smallest shape that preserves existing consumers.

## Non-trigger

A mechanical edit with known behavior uses the existing simple-work and code contracts. Do not turn it into a panel, benchmark or architecture exercise.
