# Decision example

One failed migration led to a proposed always-read-all-docs rule.

Reject the universal rule. Capture the concrete compatibility boundary and add an executable migration check if authorized. A lesson needs scope and a counterexample.

## Non-trigger

A mechanical edit with known behavior uses the existing simple-work and code contracts. Do not turn it into a panel, benchmark or architecture exercise.
