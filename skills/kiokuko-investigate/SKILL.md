# Investigate

Follow SOUL and the current host directive. This skill grants no extra permissions, model changes or delegation. Use the current model and proportionate evidence.

Trace the actual entry point, state, effects, failures and consumer result. For rationale, inspect relevant history and authorized sources; code alone cannot prove intent. Separate observed facts, historical evidence, inference and unknowns. Explain the smallest complete answer at the requested depth. Never mine other chats or search unrelated sources.

## Completion

Evidence: cite paths and relevant lines or source links. Record missing sources and contradictions. Stop when the question is answered; do not turn explanation into an unsolicited refactor.

Read [worked cases](references/cases.md) only when the decision or failure boundary is unclear. Do not load unrelated specialists or repeat completed checks without new evidence.
