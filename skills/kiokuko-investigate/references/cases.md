# Decision example

A retry function has a five-second delay but no rationale in history.

Trace when the retry runs and cite the constant. State that its historical motivation is unknown; do not invent an outage story.

## Non-trigger

A mechanical edit with known behavior uses the existing simple-work and code contracts. Do not turn it into a panel, benchmark or architecture exercise.
