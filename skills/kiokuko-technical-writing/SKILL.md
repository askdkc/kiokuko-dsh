# Technical writing

Follow SOUL and the current host directive. This skill grants no extra permissions, model changes or delegation. Use the current model and proportionate evidence.

Lead with the usable answer. Choose explanation, how-to, tutorial or reference based on the reader goal. Use real identifiers and concrete actions; remove filler and vague claims. Preserve uncertainty, conditions, technical meaning and useful rationale. Do not enforce word or punctuation bans that make prose worse. Apply natural-japanese-output for Japanese.
