# Decision example

A draft says the new cache guarantees instant results, but only one warm run was measured.

Write that the warm run completed in the measured time. Preserve dataset and sample count; omit universal claims. Japanese: 測定した1回では短縮した。再現性は未確認。

## Non-trigger

A mechanical edit with known behavior uses the existing simple-work and code contracts. Do not turn it into a panel, benchmark or architecture exercise.
