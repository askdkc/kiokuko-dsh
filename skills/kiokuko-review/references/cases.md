# Decision example

A comment warns that a callback runs after disposal.

Trace registration and cleanup, reproduce a late callback if possible. Keep the warning until the constraint is disproved or structurally enforced; deleting it is not a fix.

## Non-trigger

A mechanical edit with known behavior uses the existing simple-work and code contracts. Do not turn it into a panel, benchmark or architecture exercise.
